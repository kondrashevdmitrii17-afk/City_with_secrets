# Minecraft City Mod

Этот скрипт позволяет генерировать целый городской квартал с многоэтажными зданиями, парками, дорогами, уличным освещением и движущимся транспортом на сервере Minecraft с помощью команд в игровом чате.

## Требования к системе

1. Установленный **Python** версии 3.8 или выше.
2. Установленная и обновленная библиотека `mcpi`. 
   > **Важно:** Если вы устанавливали базовый API из архива `minecraftPythonAPI.zip` (пакет `py3minepi`), библиотека `mcpi` там устаревшая и не поддерживает чтение чата. Обязательно обновите её через терминал/командную строку:
   > ```bash
   > pip install --upgrade mcpi
   > ```
3. Запущенный сервер **Minecraft** (версия 1.11.2, например Spigot/Paper) с установленным плагином **RaspberryJuice** (порт `4711`).
4. Клиент **Minecraft** (версия 1.11.2), подключенный к этому серверу.

## Как запустить

1. Запустите сервер Minecraft (например, через `Start_Server`).
2. Зайдите на сервер через клиент игры (подключитесь к `localhost` или IP-адресу вашего сервера).
3. Запустите скрипт `City.py` через терминал или IDE:
   ```bash
   python City.py
